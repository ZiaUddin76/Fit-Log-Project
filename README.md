# 💪 FitLog — Workout & Fitness Tracker

A modern, responsive workout tracking application built with Next.js to help users explore exercises, save workouts, and organize their daily fitness routines.

**🌐 Live Website:** [FitLog](https://fit-log-project-mu.vercel.app/)

**📂 GitHub Repository:** [Fit-Log-Project](https://github.com/ZiaUddin76/Fit-Log-Project)

## 🌐 Overview

**FitLog** is a fitness web application designed to make workout planning and exercise discovery simple and accessible. It provides a dedicated workout library, saved exercises, and personalized daily workout plans through a clean, gym-inspired interface.

The application features a dark UI with a vibrant lime-green accent, creating a modern fitness-focused experience across different screen sizes.

This project is part of my journey toward becoming a professional web developer, where I'm building practical experience with modern frontend technologies, component-based architecture, responsive design, and deployment.

## ✨ Features

- 🏋️ **Workout Library** — Browse and explore available workouts and exercises.
- 📚 **Exercise Collection** — Discover exercises through a dedicated library.
- 📋 **My Plan** — Access and organize saved exercises and daily workout plans.
- 🎯 **Workout Details** — View individual workout information through dedicated detail pages.
- 🎨 **Modern UI** — Enjoy a dark, gym-inspired design with a vibrant lime-green accent.
- 📱 **Responsive Design** — Access the application across desktop, tablet, and mobile devices.
- 🧩 **Reusable Components** — Maintain a consistent interface through reusable React components.
- ⚡ **Next.js Architecture** — Build a modern web experience using Next.js and React.

## 🚀 Getting Started

Follow these steps to run FitLog locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/ZiaUddin76/Fit-Log-Project.git
```

### 2. Navigate to the project directory

```bash
cd Fit-Log-Project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit [http://localhost:3000](http://localhost:3000) in your browser.
