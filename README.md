# FitLog

FitLog is a workout library that helps users discover exercises, build a daily workout plan, save workouts for later, and track their progress.


## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- React Icons
- React Toastify
- REST API


## Key Features

- Browse a workout library with exercise details, categories, equipment, duration, calories, and ratings.
- View detailed workout pages with instructions, specifications, and workout information.
- Add workouts to Today's Plan or save them for later.
- Manage workouts from the My Plan page with sorting, tabs, mark as done, and remove functionality.
- Responsive dark-themed UI with dynamic counters, toast notifications, loading states, and a custom 404 page.
